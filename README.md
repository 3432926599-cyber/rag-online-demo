# 招投标知识库 · RAG 问答（静态演示）

Static demo of a RAG question-answering system over tender/bidding documents (LlamaIndex + ChromaDB + DeepSeek).

- 单文件静态演示：界面与真实产品一致，内置 19 个实测问题的**真实答案 + 引用原文 + 相似度**。
- 数据全部为「虚构·脱敏」测试数据，不含真实单位/人员/金额，亦无 API Key。
- 页面为只读演示（静态托管，无后端）：上传/删除/预览等操作会提示「演示模式」。

Live: https://3432926599-cyber.github.io/rag-online-demo/
